# 重复日程功能设计方案

## 📋 概述

本方案基于后端 API 文档实现重复日程功能，采用**模板-实例分离**架构，支持灵活的重复规则配置和用户友好的交互体验。

---

## 🏗️ 架构设计

### 核心概念

1. **模板 (Template)**
   - 存储重复规则和基础配置
   - 不直接显示在日历上
   - 后端自动管理

2. **实例 (Instance)**
   - 根据模板生成的具体某一天的任务
   - 用户实际看到和操作的对象
   - 每个实例独立可编辑

3. **懒生成 (Lazy Generation)**
   - 不会一次性生成未来所有实例
   - 后端定时任务滚动生成下一个实例

## 📦 数据模型

### 1. RecurrenceRule 类 (`lib/models/recurrence_rule.dart`)

```dart
class RecurrenceRule {
  final String frequency;      // DAILY, WEEKLY, MONTHLY, YEARLY
  final int interval;           // 间隔（默认 1）
  final List<String>? byDay;    // 周几重复（仅 WEEKLY 有效）
  final DateTime? until;        // 截止日期
  final int? count;             // 重复次数
}
```

**关键方法：**
- `toJson()` - 转换为后端 JSON 格式
- `fromRRule(String)` - 解析后端返回的 RRULE 字符串
- `toDisplayText()` - 转换为用户友好文本

### 2. Schedule 模型扩展

新增字段：
```dart
final String? parentId;        // 重复日程模板 ID
final int? iterationIndex;     // 第几次实例（从 1 开始）
```

## 🎨 UI 组件

### 1. RecurrenceEditor 组件 (`lib/widgets/recurrence_editor.dart`)

**功能：**
- 重复规则的完整配置界面
- 支持频率、间隔、周几、结束条件的设置
- 实时预览规则文本

**配置项：**

#### 频率选择
- 每天 (DAILY)
- 每周 (WEEKLY)
- 每月 (MONTHLY)
- 每年 (YEARLY)

#### 间隔设置
- 下拉选择：1-10
- 单位根据频率自动调整（天/周/月/年）

#### 周几选择（仅 WEEKLY）
- 多选 FilterChip
- 至少选择一天
- 支持：周一~周日

#### 结束条件
- **永不结束**：持续生成
- **截止日期**：选择具体日期
- **重复次数**：输入次数（1-999）

**使用示例：**
```dart
RecurrenceEditor(
  initialRule: existingRule,
  onChanged: (rule) {
    setState(() {
      _recurrenceRule = rule;
    });
  },
)
```

### 2. RecurrenceHelper 工具类 (`lib/utils/recurrence_helper.dart`)

**功能：**
- 判断是否为重复日程
- 构建重复标识徽章
- 解析 RRULE 为用户文本
- 构建系列操作提示

**方法：**
```dart
RecurrenceHelper.isRecurringInstance(schedule)     // 是否为重复实例
RecurrenceHelper.buildRecurrenceBadge(schedule)    // 构建徽章 Widget
RecurrenceHelper.parseRRuleToText(rrule)           // 解析 RRULE
RecurrenceHelper.buildSeriesOperationWarning()     // 操作提示
```

## 🔄 数据流

### 创建重复日程

```
用户输入
  ↓
RecurrenceEditor 配置
  ↓
RecurrenceRule.toJson()
  ↓
Schedule.recurrence (JSON 字符串)
  ↓
POST /api/schedules
  ↓
后端创建模板 + 第一个实例
  ↓
后端定时任务生成后续实例
```

### 编辑单个实例

```
用户点击编辑
  ↓
检查 parentId
  ↓
显示系列操作提示
  ↓
只修改当前实例
  ↓
PUT /api/schedules/{id}
  ↓
不影响其他实例
```

### 显示重复标识

```
Schedule 加载
  ↓
检查 parentId / recurrence
  ↓
显示重复徽章（紫色）
  ↓
显示第 X 次
  ↓
解析 RRULE 为文本
```

- 紫色徽章：🔁 重复 ·3（第 3 次）

### 3. 日程详情页

**重复信息区域：**
```
🔁 重复规则
   每周（周一、周三、周五）

```

### 4. 编辑重复实例

**提示信息：**
```
ℹ️ 这是重复日程的一个实例
   修改只影响这一次，不会影响系列中的其他实例
```

## 📝 文本展示规则

### RRULE 解析示例

| RRULE | 显示文本 |
|-------|---------|
| `FREQ=DAILY;INTERVAL=1` | 每天 |
| `FREQ=WEEKLY;INTERVAL=2` | 每 2 周 |
| `FREQ=WEEKLY;BYDAY=MO,WE,FR` | 每周（周一、周三、周五）|
| `FREQ=MONTHLY;INTERVAL=1;UNTIL=20261231` | 每月，截止到 2026-12-31 |
| `FREQ=WEEKLY;COUNT=10` | 每周，共 10 次 |

## ⚠️ 注意事项

### 1. 编辑限制
- 当前版本只支持"修改单个实例"
- 不支持"从此次开始修改所有未来实例"
- 如需修改整个系列，使用 PUT /series/:id

### 2. 删除行为
- 删除单个实例不影响系列
- 删除系列提供 3 种策略：
  - `none`: 只删除模板
  - `future`: 删除模板 + 待办实例
  - `all`: 删除模板 + 所有实例

### 3. 数据同步
- 后端返回 RRULE 字符串格式
- 前端发送 JSON 格式
- RecurrenceRule 类负责转换

### 4. 性能优化
- 不一次性加载所有实例
- 按需查询特定时间范围
- 使用 parentId 分组展示
